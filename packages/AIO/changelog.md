## WIZBOX 2.1.10
- 修复: 同步时间页面有时会无法退出的bug
- 新增: 游戏库支持收藏, 右摇杆按下(R3)收藏/取消收藏, 图标右上角显示绿色星标, 收藏持久化到 config
- 新增: 游戏库菜单新增「查看收藏」, 可只看已收藏的游戏
- 新增: 游戏库左摇杆按下(L3)全选/取消全选
- 新增: 游戏库触屏支持, 点击卡片切换选中, 长按卡片安装全部游戏
- 修复: 游戏库去掉右摇杆导航, 避免按 R3 收藏时摇杆微动导致光标位移; D-Pad 与左摇杆导航不变
- 修复: 收藏文件改为原子写入, 避免写入中断时收藏被清空
- 修复: 打开游戏库后退出应用会提示软件出错, 原因是退出锁未及时解除导致系统强杀进程
- 优化: 统一所有弹窗设计
- 优化: 系统屏蔽 `system_settings.ini` 的同步设置
## WIZBOX 2.1.9
- 修复: AIO 应用选项因为异步被重置的问题, 改为固化到config.ini, 安装列表自动应用
