## WIZBOX 2.1.1
- 新增: 应用商店 AIO 菜单增加 `更新日志`，打开即可查看新版本包含哪些变化，支持方向键/摇杆滚动
- 新增: 应用商店 AIO 快捷保留项菜单（加号键呼出），可快捷调整保留引导 / KIP / DBI
- 新增: 应用商店条目菜单增加 `同步刷新`（AIO 除外），无需卸载即可清理残留的安装记录，不会删除已安装文件和自定义覆盖
- 修复: 更新安装 AIO 后不能正常显示 `已安装`
- 修复: 打开应用商店 AIO 安装列表后快速退出可能崩溃
- 修复: 退出应用时黑屏时间偏长：后台任务、下载与网络请求现在会立即取消，不再等待超时
- 修复: 超频等后台模块在开关或重启后立即退出应用时可能出现的异常
- 修复: 云盘页面快速离开或退出时，列表加载、删除、分享保存与游戏目录查找会卡住或误报失败
- 修复: 云盘安装的下载进度与速度长时间不变后一次跳满，大小标签还会回退
- 修复: 云盘安装确认页的游戏封面一直显示字母占位，现在会自动补齐
- 修复: 安装列表编辑器在本地已有清单时一直显示加载动画并吞掉输入，现在会立即打开
- 修复: 未安装的包打开一次安装列表后会被误显示为 `已安装`
- 修复: 清除游戏库封面缓存后封面不会恢复下载，重进游戏库现在会按当前画面补齐
- 修复: 长时间浏览游戏库与应用商店后内存持续增长，图标/封面偶尔显示异常
- 修复: 超频工具扫描硬件或下载配置时无法立即退出，现在加载中也能按 B 或 L/R 离开
- 优化: 安装记录、订阅覆盖等状态改为断电安全写入，强制关机不会留下损坏或半截文件
- 优化: `同步安装记录`入口移到 AIO 条目菜单的 `安装列表`下一项，选中 AIO 时即可直接校准, 应用商店总览菜单不再重复提供
- 优化: 条目详情页的侧菜单标题改为 `应用选项`, 分类总览仍保留 `应用商店选项`
- 优化: 侧菜单只在选中可安装条目与分类总览时打开
- 优化: 自动超频同时写入 CPU 频率上限（2805 MHz），此前沿用 KIP 默认上限导致高频被压住。
- 优化: 确认弹窗的左右选择支持右摇杆（原先只有方向键与左摇杆）。
- 优化: 绿色加载动画改为转动圆圈, 避免卡顿问题
- 修复: WIZBOX 自更新版本号颜色错误的问题
